# Popamp Bar

# ⚠️ This skin was generated automatically

## It needs a designer's edits to make it simpler

The pictures were written by a program, not drawn by a designer, so the
files are more complicated than the skin needs. Fork it and redraw it.

Popamp Modern as a bar: the main window is a strip 14 pixels high across the bottom (or top) of the screen, reserved like a taskbar, with the playlist and the equalizer against its right end.

![Popamp Bar: the bar at the bottom of the screen with the equalizer and the playlist above its right end](preview.png)

The picture leaves out the middle of the bar, which runs the whole width of the screen.

A vector skin for [Popamp](https://github.com/popamp/popamp), skin format
version 1. All artwork is the skin's own.

## Install

With Popamp 0.6.0 or newer from [apt.popamp.app](https://apt.popamp.app):

```sh
sudo apt install popamp-skin-bar
```

Then pick it in the main menu's skin list. Or clone it into Popamp's
skins folder, where a copy of the same name wins over the package:

```sh
git clone https://github.com/popamp/skin-bar ~/.local/share/popamp/skins/bar
```

Updating is `git pull` in that folder; Popamp reloads the skin.

## Rebuild

Everything here is generated by one script. It needs `python3-fonttools`
and `fonts-dejavu-core`:

```sh
python3 -I -B tools/gen_modern_skin.py . bar
```

Change the script, not the generated files.
